overall progress
  1. One course at a time. Finish it or drop it before starting the next.
  2. Build while you learn. Every phase ends with a project that becomes a real piece of the hedge fund. About one hour of building per hour of watching.
  3. Code along, don't just watch. Pause, type the code yourself, change it, break it, fix it.
  4. Test out of what you know. Try the phase project first; if you can do it, skip ahead.
  5. Use Google Colab for heavy work. Your 8 GB laptop will struggle with machine learning; Colab runs Python in the browser for free.
  6. Books fill the gaps. Grus → Jansen → Bishop slots into Phases 1–4.
  7. Watch long courses at 1.25x, write notes in your own words, and quiz yourself with five questions at the end of each session.
